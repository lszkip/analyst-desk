# Memory policy

Analyst Desk keeps owner-scoped memory in a local LangGraph `SqliteStore`, separately from run checkpoints and the evidence journal. The authenticated application selects the owner; models and requests cannot select another owner's store. Database permissions are `0600`. This is local access control, not encryption or protection against a compromised host account.

**What is retained.** Explicit operator preferences use allowlisted presentation, detail and risk-focus values. Published-note history retains note identity, exact content hash, company/year scope and citations after the publication hook checks the approval, source receipts and rendered note. Coverage means prior request coverage, not exhaustive filing coverage. Private watchlist labels and annotations stay in authenticated local CRUD. Conditional lessons remain drafts until a person explicitly approves or rejects their exact proposal hash with a reason. AI recommendations do not count as that approval.

**What reaches a model.** Context contains bounded preferences and at most three relevant prior-note summaries, capped by default at 6,000 characters; omissions are marked. Memory is historical context, not fresh evidence. Current claims still need current retrieval and verification. A follow-up can compare source inventories but cannot infer changed business risks from changed lists alone. The stored `/notes/...` value is a reference convention, not a demonstrated browser route. SEC source links remain provenance references. Freeze model-visible memory with the reviewed run configuration; do not silently alter an approved task.

**Correction, deletion and privacy.** Owner operations require the current content hash. Published snapshots are immutable: delete the stored history entry or publish a separate correction. Deleting a note also deletes its coverage row. Deletion does not remove external backups. Each owner/category is capped at 500 entries, without silent expiry or eviction. Private watchlists never enter context; a normalized literal check runs before every external model/tool dispatch, including memory-off mode. A public ticker exception applies only to the trusted request's ticker scope. This check does not cover arbitrary paraphrase, encoding or all fragments. Do not export memory databases or private watchlists as evidence.

**Observed comparison.** The actual S37 laptop report replayed the same archived S25 Google/Meta note and 18-citation inventory. Memory off supplied zero notes and 131 context characters; memory on supplied one note and 5,549 characters, without truncation. Both modes blocked the synthetic private literal. There were zero model/network calls. The status remains `historical_publication_confirmed_not_current_source_reverified`; historical critic limitations are retained. This measures context behavior, not improved model quality or current risk stability.
