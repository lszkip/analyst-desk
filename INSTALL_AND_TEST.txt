HOW IT WORKS
- The model can select the existing financial tool or a supported direct reply.
- Final AI responses are structured JSON drafts, not unrestricted prose.
- Python checks claim company, concept, fiscal year, dates, exact integer amount,
  currency and evidence reference against the tool results.
- All successful tool results must be represented exactly once.
- Python renders the final answer from the evidence after validation.
- Without tool evidence, only predefined clarification/explanation replies can
  be returned. This prevents unverified financial figures in free-form text.
- Missing/conflicting tool results produce fixed, honest status explanations.
- An invalid draft is blocked with HTTP 502 and code output_guardrail_blocked.
  There is no automatic correction retry yet.

SCOPE AND LIMITS
This is a deliberately bounded first guardrail for Microsoft annual net income.
Basic definitions of revenue, profit and net income have predefined wording.
Other companies, metrics, calculations and broad free-form explanations are not
supported by this version. We will extend these capabilities in later steps.

The check establishes agreement with retrieved tool evidence. It does not
independently authenticate SEC files, prove the source figure is correct,
prove the model chose the right tool/year for the user's intent, or check
which requested years the model omitted before retrieval. These need separate
data-selection tests and live evaluation. The current lookup uses the latest
matching filing, not an 'as known at that time' historical policy.

VALIDATION
18 offline tests passed locally before packaging. They use simulated AI and
lookup responses and make no external calls. They test both successful answers
and deliberate wrong amounts, years, companies, concepts, dates, currencies,
references, missing evidence, duplicate/omitted claims and malformed output.
These are software checks, not an evaluation of live model accuracy.
The local validation imported a reconstruction of the previously supplied
financial_tools.py; your real tool and file must be checked on your laptop.
No live request using your IIT key was performed while preparing this update.

The current OpenRouter documentation describes JSON-schema structured output:
https://openrouter.ai/docs/guides/features/structured-outputs
The model page lists tool calling and structured-output support:
