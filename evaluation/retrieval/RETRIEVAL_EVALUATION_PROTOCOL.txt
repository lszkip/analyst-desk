METRICS
Raw Recall@5 = unique relevant hits in the original first five positions / all gold.
Precision@5 = unique relevant hits in those positions / 5. Missing positions score zero.
Hit rate@5 = fraction of queries with at least one relevant result in those positions.
Binary nDCG@5 = discounted relevant gain / the ideal discounted gain. Rank r has
discount 1/log2(r+1), relevance gain is 0 or 1, and ideal ranks run from 1 through
min(5, number of gold passages). All relevant passages are equal within the binary
rubric; this does not measure answer completeness, facet diversity or factual accuracy.
Duplicate IDs never gain credit twice and never promote rank six. The search-response
contract rejects duplicate IDs as a retrieval error. Invalid/unknown/out-of-scope IDs
and missing/stale source hashes are errors. Every error scores zero and stays in the
macro denominator. Do not drop failing questions.

PRIMARY DEVELOPMENT GATE
Mean hybrid_rerank nDCG@5 >= 0.70, at least 40 reviewed cases, zero retrieval errors,
and no macro nDCG@5 or raw Recall@5 regression against hybrid (tolerance 1e-12).
This 0.70 nDCG target is a project-chosen development criterion, not an IIT requirement
or an equivalent to 70% recall. It is declared before the run and must not be lowered
afterward merely to make a failed run pass. An explicit regression override is recorded;
the packaged runner does not enable it.

The prior 0.70 raw Recall@5 gate was infeasible for the exhaustive gold sets and is
retired as the default criterion. Mean raw Recall@5 can reach only 0.4530301377234023
with five results, even under ideal retrieval. Precision@5 can reach only 0.805 because
11 cases have fewer than five relevant passages. nDCG@5 can reach 1.0 for every case.
An optional raw recall threshold is still supported; impossible targets fail before
model loading/search. Do not describe the changed nDCG criterion as improved recall.

BRIEF AND LIMITS
The original project brief (physical page3) requires Recall@5 on 30+ labelled queries,
before/after one change, and evaluation in CI failing below a threshold; it supplies
no numeric retrieval threshold. We retain exhaustive Recall@5 and use 40 queries.
The CLI exits nonzero on quality-gate failure. New offline metric tests are added to
the existing GitHub test command. A real-data quality CI run and failed-run evidence
remain to be collected; this package does not claim those happened.
These development labels were created with Claude drafts and subsequent AI review,
not independent human adjudication. Measured development scores are not held-out
generalization evidence or a completed capstone evaluation.
